Technical walkthrough · time-series forecasting

How the forecasting comparison was built, phase by phase

At a glance
  1. 1 · WhatA fair head-to-head of 15 forecasting methods on transformer oil temperature, 24 hours ahead, including three zero-shot foundation models.
  2. 2 · WhyTeams must choose between fast statistics, machine learning and new pretrained models; this repo's first benchmark was not like-for-like.
  3. 3 · WhoUsers: forecasting and data science teams in utilities and operations.
  4. 4 · WhereResults page and technical walkthrough on GitHub Pages; dashboard on Streamlit Community Cloud (still the original benchmark).
  5. 5 · When it failsPass mark fixed before any run: the zero-shot champion must beat the trained champion by ≥ 5%, pass a significance test, and win on the last 41 days.
  6. 6 · HowEvery model forecasts 24 hours from the same history at 145 start points; champions picked on validation; Diebold–Mariano test.
Skills applied, with proof
  • Time-series forecasting ARIMA, Holt-Winters, Prophet, gradient boosting, LSTM, N-BEATS ADR-004 rolling_trained.py
  • Foundation models Chronos-2, TimesFM-2.5 and Moirai-2.0, zero-shot on a laptop CPU rolling_foundation.py ADR-008
  • Evaluation and statistics rolling-origin backtest, MASE, quantile loss, Diebold–Mariano test with small-sample correction rolling.py rolling_report.py
  • Experiment design pass mark set before the runs, leakage tiers, every deviation logged ADR-008
  • Reinforcement learning LinUCB bandit that picks a model per day ADR-007
  • MLOps and CI Optuna tuning, dashboard on precomputed results, CI with protocol and gate tests ci.yml test_rolling.py
